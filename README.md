# Connor Sequeira Portfolio

Personal GitHub Pages portfolio for Connor Sequeira, focused on robotics, automation, embedded systems, machine learning, and mechatronics projects.

Live site: https://connorsequeira.github.io/

## Repository Structure

- `index.html` - main GitHub Pages landing page.
- `assets/` - shared CSS, JavaScript, webfonts, Sass sources, and the current resume PDF.
- `images/` - images used by the main landing page.
- `portfolio/` - extended project gallery and individual project pages.
- `CNAME` - custom GitHub Pages domain configuration.

## Key Files

- Current resume: `assets/Connor.Sequeira.Resume.pdf`
- Main portfolio page: `index.html`
- Project gallery: `portfolio/index.html`

## Maintenance Notes

- Keep only one current resume PDF in `assets/` and update links in `index.html` if the filename changes.
- Avoid committing temporary index snapshots such as `v2-index.html` or `old-index.html`; Git history already preserves previous versions.
- Before removing media from `images/` or `portfolio/images/`, search for the filename across HTML, CSS, and JavaScript files.
- This is a static site, so it can be previewed by opening `index.html` locally or by serving the folder with any simple static server.
