# Portfolio Gallery

This folder contains the extended project gallery for the portfolio site.

## Structure

- `index.html` - gallery landing page that links to individual project pages.
- `assets/` - CSS, JavaScript, Sass, and webfont files used by the gallery.
- `images/fulls/` - full-size gallery media.
- `images/thumbs/` - thumbnail media used by `portfolio/index.html`.
- `portfolio_files/` - individual project pages and their local assets.

## Linked Project Pages

The gallery currently links to these project folders:

- `portfolio_files/3DVIS/`
- `portfolio_files/AIVIS/`
- `portfolio_files/PREMOTION/`
- `portfolio_files/TH/`
- `portfolio_files/PTP/`
- `portfolio_files/EOTD/`
- `portfolio_files/AL/`

When adding or removing a project, update `portfolio/index.html` and keep the corresponding media files together with that project folder.
